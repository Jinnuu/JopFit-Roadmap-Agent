# AI 백엔드 인턴 직무 역량 사전

AI 서비스 백엔드 개발자는 인공지능 모델(특히 LLM)과 서비스 백엔드를 매끄럽게 연결하고, 안정적이며 응답이 빠른 API를 제공하는 역할을 합니다.

## 핵심 요구 역량
- **API 개발 및 최적화**: Python(FastAPI, Django, Flask)을 이용한 고성능 비동기 API 개발 능력.
- **LLM API 연동**: OpenAI API, Anthropic API, 혹은 HuggingFace 오픈소스 모델 활용 능력.
- **RAG 및 Vector DB**: 외부 문서를 적절히 임베딩(Embedding)하고, Chroma, FAISS, Qdrant 등의 Vector 데이터베이스를 이용해 필요한 지식을 고속으로 검색(Retrieval)하는 아키텍처 구현 능력.
- **컨테이너 배포**: Docker 및 Docker Compose를 통한 애플리케이션 및 Vector DB 통합 배포 역량.
- **로그 및 모니터링**: 사용자 입력 로그 및 LLM 토큰 사용량, 성능 지표 수집 및 분석 경험.
