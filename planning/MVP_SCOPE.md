# JobFit Roadmap MVP 범위 정의서

## 1. MVP 목표
본 **MVP(Minimum Viable Product)**의 목표는 개인화된 취업 준비 프로세스를 지원하기 위해, 회원 계정 체계를 구축하고 사용자별 경험/프로젝트/자기소개서 데이터를 지속 가능한 저장소로 통합하는 것입니다. 더불어, 사용자가 입력한 공고를 기반으로 수행한 AI 분석 기록을 저장하고, 이를 통해 도출된 주차별 로드맵(Roadmap Task)과 관심 기업/직무를 사용자가 대시보드 형태로 체계적으로 관리할 수 있는 최소 기능 단위의 인프라 및 사용자 가치를 검증합니다.

---

## 2. MVP In-Scope (개발 범위 포함 사항)
MVP 단계에서는 아래의 기능군을 포함하여 개발합니다.

* **인증 및 회원 관리 (Auth & User)**
  - 이메일 기반 회원가입 및 로그인 기능
  - JWT 발급 및 API 요청 인증 필터
  - 현재 로그인한 사용자의 프로필 조회 및 관리
* **개인 취업 데이터 관리 (User Data CRUD)**
  - 경험(Experience) CRUD: 활동 유형, 기간, 내용, 획득 역량 등
  - 프로젝트(Project) CRUD: 프로젝트명, 역할, 핵심 성과, 적용 기술 등
  - 자기소개서 초안(ResumeDraft) CRUD: 문항, 답변 내용, 작성일 등
* **관심 설정 관리 (Preferences)**
  - 관심 기업(Preferred Company) CRUD 및 관심 직무(Preferred Role) CRUD
* **공고 분석 및 이력 저장 (Analysis)**
  - 채용공고 본문 텍스트 직접 입력 기반의 Fit-Gap 분석 (기존 기능 연계)
  - 분석 실행 결과를 사용자 계정별로 데이터베이스에 저장
  - 이전 분석 기록 목록 조회 및 특정 분석 상세 결과 재조회
* **로드맵 및 태스크 관리 (Roadmap & Tasks)**
  - 분석 결과 보고서에서 도출된 주차별 준비 계획을 '내 로드맵'으로 저장
  - 저장 시 주차별 세부 과제(`RoadmapTask`) 자동 생성 및 DB 저장
  - 각 과제의 상태 관리: `To-Do` (진행 대기) / `Doing` (진행 중) / `Done` (완료)
* **알림 (Notification)**
  - 마감일 임박 태스크, 완료되지 않은 로드맵 리마인드 등 앱 내부 알림 목록 조회 및 읽음 처리
* **인공지능 추천 에이전트 (Recommendation Agent)**
  - 사용자가 누적 등록한 경험/프로젝트의 스택 및 성과 태그를 기반으로 맞춤형 추천 직무 및 기업 유형 제안 Agent
* **인프라 및 시스템 설정**
  - 개발 생산성 및 비용 관리를 위한 '기본 Mock 모드'와 '개발자 LLM 모드' 전환 구조 유지

## 3. MVP Out-of-Scope (개발 범위 제외 사항)
아래의 기능들은 기술적 복잡도, 법적 검토 필요성 또는 리소스의 한계로 인해 이번 MVP 범위에서 제외하며, 향후 고도화 단계에서 진행합니다.

* **외부 채용 정보 자동 수집**
  - 잡코리아, 사람인, 링커리어, 원티드 등 주요 구인구직 사이트의 자동 백그라운드 크롤링 및 파싱
  - 실시간 외부 채용공고 검색 엔진 연동
* **채널 다각화 알림**
  - SMS 발송, 카카오톡 알림톡 전송, 사용자 이메일 direct 발송 기능
* **비즈니스 모델 및 관리 인프라**
  - PG사 연동을 통한 결제/구독 시스템
  - 관리자 및 대시보드 모니터링 어드민 페이지
* **고급 분석 및 문서 변환**
  - 합격 가능성 수치 점수화 (정량적 합격률 예측 모델)
  - 분석서의 고급 PDF 리포트 파일 생성 및 내보내기
* **고도화된 RAG 및 검색**
  - `pgvector`를 활용한 벡터 임베딩 기반의 시맨틱(Semantic) RAG 검색 엔진
  - 구글 캘린더 등 외부 캘린더 일정 양방향 동기화
* **문서 파싱 파일 업로드**
  - PDF, HWP, DOCX 이력서/포트폴리오 업로드 시 텍스트를 파싱하여 자동 경험 등록하는 기능

## 4. 우선순위 (Priority)

구현의 시급성과 의존 관계에 따라 기능을 P0, P1, P2 등급으로 분류합니다.

| 분류 | 기능 단위 | 세부 항목 | 비고 |
| :--- | :--- | :--- | :--- |
| **P0** | **인증 및 인프라 구축** | - 이메일 회원가입 및 로그인<br>- JWT 인증 필터<br>- PostgreSQL 연결 및 SQLAlchemy 모델 정의 | 서비스의 근간이 되는 기초 데이터와 계정 인프라 |
| | **핵심 취업 자산 CRUD** | - 경험(Experience) CRUD<br>- 프로젝트(Project) CRUD<br>- 자기소개서 초안(ResumeDraft) CRUD | 사용자의 기본 정보 제공 파트 |
| | **분석 및 로드맵 저장** | - 공고 본문 입력 기반 분석 및 DB 저장<br>- 이전 분석 기록 목록/상세 조회<br>- 분석서 기반 로드맵 및 Task 생성 | 핵심 분석 라이프사이클의 영속화 |
| **P1** | **목표 및 상태 관리** | - 관심 기업/직무 등록 및 이력 연계<br>- RoadmapTask 상태 변경 (To-Do, Doing, Done) | 사용성 극대화 및 지속적인 태스크 트래킹 |
| | **알림 및 추천 피드백** | - 앱 내부 알림 목록 및 읽음 처리 API<br>- 저장된 경험 기반 추천 직무/기업 유형 Agent | 사용자 유지 및 인텔리전트 인터랙션 |
| **P2** | **URL RAG 및 수집** | - URL 복사 기반 공고 본문 자동 수집 (단순 스크래핑)<br>- 사용자별 RAG 문서 수집 및 매핑<br>- 실시간 웹 검색 Agent 기초 설계 | MVP 후반 또는 다음 릴리즈 단계 |

## 5. 성공 기준 (Success Criteria)
본 MVP의 성공 여부는 다음 기준들이 모두 달성되었는지를 기준으로 판단합니다.

1. **데이터 영속성 확보**
   - 사용자가 가입 후 등록한 경험 3건, 프로젝트 2건이 세션 종료 후 재로그인했을 때도 손실 없이 그대로 조회되어야 합니다.
2. **이력 기반 분석의 완전성**
   - 채용공고 분석 시, 사용자가 직접 프로필을 입력하지 않고도 이전에 저장해 둔 경험/프로젝트 데이터를 자동으로 파싱·결합하여 Fit-Gap 분석이 올바르게 수행되어야 합니다.
3. **분석 기록의 재사용성**
   - 이전에 분석을 완료한 특정 공고에 대한 Fit-Gap 상세 내용 및 제안 로드맵을 '이전 분석 기록 목록'을 통해 1초 이내에 다시 열람할 수 있어야 합니다.
4. **로드맵 태스크의 진척 추적성**
   - AI가 제안한 로드맵을 저장한 후, 사용자가 대시보드 화면에서 이번 주 과제를 확인하고 완료 상태(`Done`)로 전환했을 때 DB 상태가 즉각 반영되고 대시보드 진척률이 갱신되어야 합니다.
5. **추천의 유효성**
   - AI 추천 Agent가 사용자의 누적 경험 및 기술 스택 태그를 인식하여, 관련도가 높은 직무군(예: 백엔드/프론트엔드 등) 및 타깃 기업 유형을 1건 이상 맞춤형 추천 근거와 함께 반환해야 합니다.
