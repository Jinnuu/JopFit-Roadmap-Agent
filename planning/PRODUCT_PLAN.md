# JobFit Roadmap 제품 기획서

## 1. 제품 개요
**JobFit Roadmap**은 구직자가 자신의 취업 준비 자산(경험, 프로젝트, 자기소개서 초안)과 목표(관심 기업, 직무)를 체계적으로 누적 관리하고, 이를 바탕으로 채용공고와의 차이(Fit-Gap)를 AI 기반으로 분석하여 개인 맞춤형 준비 로드맵과 실천 가능한 주차별 과제를 제공하는 **AI Agent 기반 취업 준비 지원 서비스**입니다.

기존의 JobFit Roadmap이 일회성으로 채용공고와 텍스트 프로필을 비교 분석해 주는 단순 도구였다면, 확장되는 본 제품은 **사용자가 로그인하여 자신의 이력과 경험을 누적 관리**하고, 지속해서 본인의 역량 성장을 모니터링하며, 준비 상태에 따른 실시간 알림과 직무/기업 추천을 제공받는 **개인 맞춤형 취업 관리 플랫폼**으로 진화합니다.

---

## 2. 문제 정의
구직자들이 취업을 준비하는 과정에서 겪는 핵심 페인 포인트(Pain Point)는 다음과 같습니다.

1. **취업 자산의 파편화 및 관리 부재**
   - 구직자는 대학 시절 프로젝트, 인턴십 경험, 자기소개서 초안 등을 노션, 구글 드라이브, 로컬 워드 파일 등 여러 곳에 분산하여 기록합니다. 이로 인해 정작 채용공고가 열렸을 때 필요한 경험을 빠르게 탐색하고 재가공하는 데 많은 시간이 소요됩니다.
2. **반복적이고 주관적인 Fit-Gap 판단**
   - 새로운 채용공고를 볼 때마다 "내가 이 공고의 자격 요건을 충족하는가?"에 대해 매번 처음부터 자신의 기억을 더듬으며 판단해야 합니다. 객관적인 역량 차이를 분석해 주는 도구가 없어, 맞지 않는 공고에 지원하여 실패하거나 준비된 공고를 놓치는 일이 반복됩니다.
3. **일회성 조언에 그치는 로드맵의 한계**
   - 기존의 AI 분석 도구들은 "SQL 능력을 키우세요", "프로젝트의 아키텍처를 개선하세요"와 같은 단발성 피드백만 제공합니다. 구직자에게 정작 필요한 것은 이를 일상에서 실천할 수 있는 구체적인 행동 계획(Action Item)과 주차별 일정 관리입니다.
4. **목표 기업별 상이한 준비 방향 관리의 어려움**
   - 가고 싶은 기업(예: 대기업 A사, 스타트업 B사)마다 요구하는 인재상과 기술 스택이 다릅니다. 그러나 기업별로 어떤 역량이 얼마나 부족하고 무엇을 먼저 준비해야 하는지 체계적으로 비교 분석할 수 있는 대시보드가 부재합니다.

## 3. 해결 방향
이러한 문제를 해결하기 위해 JobFit Roadmap은 다음과 같은 핵심 가치를 제공합니다.

* **통합 이력 관리 (Experience Repository)**
  - 사용자는 자신의 경험, 프로젝트 이력, 자기소개서 초안을 카테고리별로 등록하고 누적 관리합니다.
* **관심 기업 및 직무 매핑**
  - 타깃으로 삼는 기업 정보와 직무 스택을 등록하여, 개인화된 취업 준비의 기준점으로 삼습니다.
* **지속 가능한 AI Fit-Gap 분석 이력 관리**
  - 분석을 실행할 때마다 사용자의 최신 프로필 정보와 공고 본문을 비교 분석하고, 그 결과를 데이터베이스에 누적 보존하여 준비 상태의 변화 추이를 추적합니다.
* **실천 중심의 주차별 로드맵 태스크화 (Roadmap Tasking)**
  - AI가 도출한 로드맵 피드백을 주차별 세부 태스크(To-Do, Doing, Done, Skipped)로 변환하여 대시보드에서 진척도를 관리하도록 돕습니다.
* **인텔리전트 알림 시스템 (Smart Notification)**
  - 마감 임박 태스크, 새로운 분석에 따른 로드맵 갱신 제안, 저장된 관심 기업의 맞춤형 조언 등을 앱 내 알림을 통해 주기적으로 제공합니다.
* **데이터 기반 역량 추천 Agent**
  - 누적된 경험과 프로젝트 데이터를 역량 분석 Agent가 분석하여, 현재 프로필로 합격률이 가장 높을 것으로 예상되는 추천 직무와 기업 유형을 제안합니다.

## 4. 핵심 사용자 시나리오

```
[회원가입/경험 등록] ──> [관심 기업/직무 설정] ──> [채용공고 분석 요청]
                                                             │
[알림 및 대시보드] <── [주차별 로드맵 태스크화] <── [Fit-Gap 결과 도출]
        │
[추천 Agent 활용] (직무/기업 추천 및 보완점 탐색)
```

1. **온보딩 및 프로필 등록**
   - 신규 사용자는 이메일로 회원가입 및 로그인을 완료합니다.
   - 마이페이지 혹은 경험 관리 탭에서 대학 프로젝트, 동아리 활동, 인턴십 등의 경험을 텍스트로 등록하고 사용한 기술 스택을 태그로 지정합니다.
2. **목표 설정**
   - 사용자는 관심 기업(예: 네이버, 토스)과 관심 직무(예: 백엔드 엔지니어, 데이터 엔지니어)를 프로필에 저장합니다.
3. **공고 기반 분석 실행**
   - 지원하고자 하는 채용공고의 본문 텍스트를 복사하여 입력창에 넣고 분석을 요청합니다.
4. **Fit-Gap 분석 및 결과 제공**
   - AI Agent는 사용자가 등록한 모든 경험/프로젝트와 채용공고 요구사항을 대조하여, '매칭되는 역량(Fit)'과 '보완이 필요한 역량(Gap)'을 상세 분석서 형태로 반환합니다.
5. **로드맵 태스크 변환 및 저장**
   - AI가 제안한 준비 로드맵(예: 4주 완성 계획)을 사용자가 확인한 뒤, '내 로드맵으로 저장' 버튼을 누릅니다.
   - 시스템은 로드맵을 주차별 개별 태스크(`RoadmapTask`)로 분할하여 사용자의 일정 관리 화면에 등록합니다.
6. **취업 준비 진척 관리**
   - 사용자는 대시보드에서 이번 주에 수행해야 하는 과제(예: "API 설계서 작성 경험 보완을 위한 사이드 프로젝트 리팩토링")를 확인하고 진행 상태(`todo` -> `doing` -> `done`)를 변경합니다.
7. **맞춤형 알림 수신**
   - 매주 월요일 아침, 이번 주차에 시작해야 할 로드맵 태스크에 대한 알림을 받습니다.
   - 마감일이 지났으나 완료되지 않은 태스크에 대해 리마인드 알림이 발송됩니다.
8. **추천 Agent 피드백**
   - 메인 화면의 추천 영역에서 AI Agent가 사용자의 누적 경험 데이터를 분석하여 "현재 등록하신 Spring Boot 경험 3건을 바탕으로 볼 때, Java 백엔드 직무가 가장 매칭률이 높습니다." 혹은 "보완이 필요한 MSA 아키텍처 경험을 쌓기 위해 이커머스 토이 프로젝트를 추천합니다."와 같은 맞춤 제안을 출력합니다.

## 5. 제품 포지셔닝
JobFit Roadmap은 시중에 존재하는 단순한 '자기소개서 작성 도구'나 '단발성 LLM 프롬프트 분석기'와 확연히 다른 포지션을 지향합니다.

| 비교 항목 | 일반 LLM 분석기 / 챗봇 | JobFit Roadmap (본 제품) |
| :--- | :--- | :--- |
| **데이터 영속성** | 세션 종료 시 대화 및 분석 결과 소실 | 사용자별 경험, 프로젝트, 분석 기록을 DB에 누적 관리 |
| **분석의 연속성** | 매번 자신의 경험을 다시 복사해서 붙여넣어야 함 | 한 번 등록해 둔 내 이력 프로필을 자동으로 참조하여 분석 |
| **피드백의 실행력** | 줄글 형태의 조언으로 끝나 실행하기 어려움 | 분석서의 로드맵을 주차별 일정 태스크로 변환하여 진척도 관리 |
| **추천 로직** | 사용자의 현재 입력값에만 의존 | 누적된 전체 이력과 관심 기업 풀을 바탕으로 최적의 경로 제안 |

본 서비스는 단순한 정보 분석 도구를 넘어, 구직자가 첫 취업 준비 시작부터 최종 합격에 이르기까지 자신의 역량을 가꾸고 실천을 추적하는 **'개인 취업 준비 운영 시스템(Personal JobPrep OS)'**으로 자리매김합니다.

## 6. 향후 확장 방향 (Next Steps)
MVP 개발 이후, 중장기적으로 다음과 같은 방향의 기능 확장을 추진합니다.

1. **자동 채용공고 수집 및 연동**
   - 사용자가 채용 사이트(원티드, 사람인 등)의 URL만 입력하면 본문을 자동으로 크롤링하여 저장하고 분석으로 연계합니다.
2. **사용자별 RAG(Retrieval-Augmented Generation) 문서 저장소**
   - 사용자가 작성한 과거 포트폴리오(PDF), 기술 블로그 포스팅 링크 등을 수집하여 RAG 검색 대상으로 활용함으로써, 더욱 정확하고 개인화된 자기소개서 피드백을 제공합니다.
3. **웹 검색 Agent**
   - 관심 기업의 최근 3개월간 언론 보도, 신규 서비스 출시 동향, 최신 기술 스택 트렌드를 AI가 실시간으로 웹 검색하여 로드맵에 반영합니다.
4. **외부 서비스 연동**
   - Google Calendar와 연동하여 로드맵 태스크 일정을 동기화하고, 마감 리마인더를 E-mail 및 Slack/카카오톡 알림으로 전송합니다.
5. **기업별 입사 준비 대시보드**
   - 지원 예정 기업별로 자기소개서 준비 상태, 면접 기출 질문 분석, 모의 면접 진척도 등을 통합 모니터링할 수 있는 전용 대시보드를 제공합니다.
